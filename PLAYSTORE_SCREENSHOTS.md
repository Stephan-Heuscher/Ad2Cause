# Play Store Screenshots & Marketing Guidance

This file contains quick guidance and recommendations for creating compelling Play Store screenshots that highlight Ad2Cause's value, onboarding flow, and key features.

Why this matters
- High-quality screenshots increase conversion rate and can communicate value faster than text alone.
- Capture key flows like onboarding, watching rewarded ads, selecting a cause, and credits applied to causes.

Recommended Screenshots (landscape or portrait depending on assets)
1. Onboarding / Welcome (show the new walkthrough first screen)
2. Watch Rewarded Ads (show watch ad button + short UI feedback)
3. Confirmed Reward / Donation (show reward confirmation + updated cause points)
4. Browse Causes (grid/list of causes, clear imagery)
5. Impact Summary / Stats (total points earned and causes supported)

Design tips
- Use consistent colors from the app theme and maintain readable text overlays.
- Use device frames in banners for visual polish.
- Add short captions (one-liners) to describe the benefit (e.g. "Watch a short video — support a cause").
- Prefer high-contrast text for accessibility and legibility.

Technical sizes & export
- Minimum screenshot size (portrait): 1080 x 1920 px (recommended)
- Minimum screenshot size (landscape): 1920 x 1080 px
- Use PNG (lossless) or high-quality JPEG.
- Keep file sizes reasonable (< 2MB each) for faster Play Store listing updates.

Accessibility & localization
- Ensure on-screen text is large enough and accessible for small screens.
- Consider localized versions of screenshots for additional markets.

Optional next steps
- Produce a short promotional video (15-30s) showing the ad -> donation flow.
- Create alternate screenshots for dark mode showcasing the dark theme.

Also see `README.md` for a high-level overview and the `app` source for layouts you can reuse to capture screenshots.
